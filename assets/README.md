# Project mark

`aircolibri-logo.png` combines AirLLM's rocket/airflow motif with Colibrì's
teal pixel hummingbird, magenta crest and orange beak. It was created with
AI-assisted image generation for this independent integration on 13 November 2026.

Original references:

- [AirLLM logo](https://github.com/lyogavin/airllm/blob/main/assets/airllm_logo_sm.png), Gavin Li / AirLLM contributors.
- [Colibrì logo](https://github.com/JustVugg/colibri/blob/main/assets/colibri-logo.svg), Vincenzo Fornaro / JustVugg.

Both original repositories use Apache-2.0; see their
[AirLLM license](https://github.com/lyogavin/airllm/blob/main/LICENSE) and
[Colibrì license](https://github.com/JustVugg/colibri/blob/main/LICENSE).
The derived mark is not an official upstream collaboration badge.
