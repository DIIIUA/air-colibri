# Fixed-text Q4 results — 13 November 2026

**Result: Q4-g64 does not pass the strict BF16 agreement gate. BF16 remains
the default.** All model runs completed; this is a quality-test failure, not
a runtime exception. These small authored texts do not establish general
language/task quality or broad model support.

## Workload and repeatability

The real Qwen3.5-9B text model processed 12 fixed texts, 80 tokens each, in
five chunks of 16: **960 prediction positions**, including **623 confident
positions** with BF16 top-1/top-2 margin >= 1.0. Inputs covered English,
Russian, Python, SQL, JSON and mixed-language text. There was no padding,
generated-token feedback, repeated EOS or change to the original forward.

The source checkpoint is F16. The baseline computes in BF16; the candidate
uses asymmetric group-64 Q4 weights and a BF16 output head. Both use the same
text tokens and persistent per-mode KV/recurrent state across chunks.

The independent BF16 repeat matched every logit bit for bit, maximum absolute
difference **0**. After the scorer correction below, a fresh BF16 reference
also matched all five saved chunks: **238,387,200 logit values**. Thus the
scoring correction did not change the model computation.

## Corrected scoring and unchanged thresholds

The initial scorer used the first index returned by `topk` as the predicted
token. Equal maximum logits can be returned in a different order from the
runtime's greedy `argmax`. This counted one tied case as a confident flip.

Protocol v2 uses greedy `argmax`; top-3 membership includes equal probability
at the third-position cutoff. The historical ordered-topk metrics are still
recorded for comparison. This changes how ties are counted, not the numeric
thresholds. The corpus, checkpoint, quantizer and model-forward sources were
unchanged. Two focused tie tests and a complete candidate rerun validated the
repair. The initial artifacts remain preserved.

| Metric | Measured | Required | Result |
|---|---:|---:|---|
| Confident positions | 623 | >= 300 | PASS |
| Confident greedy-token flips | **1 / 623** | 0 | FAIL |
| Candidate greedy top-1 within BF16 top-3 | **954 / 960 (99.375%)** | 100% | FAIL |
| Top-5 overlap | Mean 4.415625; median 5 | Mean >= 4.7 **or** median >= 5 | PASS via median |
| Mean KL(BF16 || Q4) | **0.0420848** | <= 0.03 | FAIL |
| Mean cosine similarity | **0.9870364** | >= 0.99 | FAIL |

Greedy top-1 agreement overall was **873 / 960 (90.9375%)**. The remaining
confident flip occurs at position 26 of `ru_science`, BF16 margin 1.0. It is
a difference from the reference distribution, not proof of a factual error
in a generated answer.

Supplementary mean next-token NLL was 1.980755 for BF16 and 1.995135 for Q4.
The old ordered-topk scoring reported two confident flips, 91.1458% top-1
agreement and 99.2708% top-3 agreement. **Both scoring versions fail the gate.**
KL, cosine and NLL were exactly unchanged on the Q4 rerun.

## Execution and memory

Every run completed **160 layer transfers and 160 layer computations**.
The Q4 candidate used **160 verified prepacked-cache hits**, with zero misses,
rebuilds, corruption events or requantizations. This tests an existing cache,
not fresh checkpoint conversion.

Peak Torch CUDA allocation was about **3.243 GiB for BF16** and **2.961 GiB
for Q4**. All five completed fixed-text runs reported **8.125 MiB** allocated after closing
the model. Removing the smoke runner's retained last-layer reference reduced
its earlier 426.125 MiB cleanup observation to that level; no claim of zero
process CUDA allocation is made.

The startup and layer RAM guards stayed enabled. Across all five completed
runs, sampled available RAM stayed above 4.22 GiB. The observer copies full
logits, synchronizes, scores them and writes reference artifacts; OS file-cache
state was uncontrolled. Recorded elapsed times are diagnostic costs, **not a
controlled speed comparison or a throughput claim**.

The two earlier resource-rejected attempts remain part of the history. They
were followed by three completed BF16 runs and two completed Q4 runs.
